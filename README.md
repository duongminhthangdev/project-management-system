Dự án Java Lập trình hướng đối tượng (OOP) quản lý thông tin nhân sự và nhóm dự án, có tích hợp kiểm thử tự động với JUnit 5.

##  Chức năng chính
* **Nhân sự (`Employee`, `SoftwareEngineer`)**: Quản lý thông tin, tăng lương, tính lương thực nhận.
* **Nhóm dự án (`ProjectTeam`)**: Thêm/xóa thành viên, đổi trưởng nhóm, tính tổng chi phí lương nhóm.
* **Unit Test**: Kiểm thử toàn bộ kịch bản logic với JUnit 5.

## Công nghệ
* Java (JDK 17+)
* JUnit 5
* IntelliJ IDEA / VS Code

## Hướng dẫn chạy
1. Mở dự án bằng IntelliJ IDEA hoặc VS Code.
2. Mở file `src/test/java/ProjectIntegrationTest.java`.
3. Nhấn nút **Run ▶️** để chạy bộ kiểm thử JUnit 5.
